# 微网与外部电网电力调控策略研究

> 基于线性规划（LP）、鲁棒日前调度与模型预测控制（MPC）的微网储能优化调度项目。

## 1\. 项目简介

随着分布式光伏和电池储能系统的发展，微网与外部电网之间的协同调度成为提高新能源消纳率、降低用电成本和保障供电可靠性的重要手段。

本项目围绕微网与外部电网的电力调控问题，研究在不同电价机制、负荷波动及光伏预测条件下，如何制定合理的购电计划和储能充放电策略。

项目按照数学建模论文中的四个问题逐步展开，建立了从确定性日前优化到不确定性下的滚动调度、再到实时波动电价场景的优化模型，并使用
Python 实现模型求解、全年时序仿真和结果可视化。

**项目关键词：**
微网优化调度、储能系统、线性规划、鲁棒优化、模型预测控制、能源管理系统、全年仿真。

## 2\. 研究问题与解决方案

### 问题一：确定条件下的日前优化调度

在电价、负荷和光伏预测数据已知的情况下，以全天购电费用最小为目标，建立日前调度线性规划模型。

主要考虑：

* 微网供需电能平衡约束；
* 储能系统荷电状态（SOC）动态转移约束；
* 储能充放电功率限制；
* 储能容量安全边界；
* 0:00 与 24:00 储电量闭环约束。

采用 SciPy `linprog` 接口调用 HiGHS
求解器，获得全天购电及储能充放电策略。

**论文给出的主要结果：**

* 全天购电量：59,482.70 kWh；
* 全天购电费用：35,126.95 元；
* 储能初始及末端储电量：6,000 kWh；
* 储能安全运行区间：\[1,200, 10,800] kWh。

结果显示，储能能够结合分时电价和光伏出力进行充放电调度，在满足供电约束的同时降低购电成本。

### 问题二：考虑负荷与光伏波动的日前鲁棒调度

针对实际负荷和光伏出力存在不确定性、供电不足时需要承担 5
倍电价紧急购电惩罚的情况，建立"日前鲁棒计划 + 日内 EMS
状态机执行"的两阶段调度框架。

主要方法：

1. 利用历史数据构建日前负荷与光伏预测；
2. 对负荷预测进行上偏处理，对光伏预测进行保守下折；
3. 设置 300 kWh 储能安全防御缓冲；
4. 通过线性规划求解日前计划购电量；
5. 日内根据实际负荷、光伏出力和储能状态执行能量管理策略；
6. 当储能无法继续满足负荷需求时，触发紧急购电。

代码采用前 7 日历史数据进行加权预测，并通过全年 365
天逐日滚动仿真，分析不同季节下的供电风险和经济性。

### 问题三：引入光伏预测更新的多阶段 MPC 调度

在问题二的基础上，引入每天 0:00、6:00、12:00、18:00
四次光伏预测更新机制，建立日前基准计划、日内滚动调整和实时 EMS
执行相结合的三阶段调度框架。

主要方法：

* 0:00 根据日前预测制定全天基准购电计划；
* 6:00、12:00、18:00
根据最新光伏预测和当前储能状态，对剩余时段进行滚动优化；
* 将购电增量与核减量分别建模，处理非对称结算规则；
* 使用线性规划求解日内调整问题；
* 通过 EMS 状态机完成实际充放电与紧急购电执行。

代码中将整点光伏预测数据插值到 10 分钟调度时步，使用 `numpy.interp`
进行线性插值。

**论文给出的主要结果：**

以 2025 年 12 月 21 日为例，日内动态纠偏使紧急购电量由 20,647 kWh 降至
6,247 kWh，降幅约为 69.7%。

论文还从预测信息增益、储能响应和边际效益等角度分析了预测更新频率的合理性。

### 问题四：实时波动电价下的通用调度模型

进一步考虑外部电网实时电价波动，将微网内部物理约束与多级购电结算机制结合，建立兼容实时电价场景的通用时序优化模型。

通过切换日内调整机制，对比两种运行模式：

* 问题 4-2：日前鲁棒调度模式；
* 问题 4-3：日内多时序滚动 MPC 调度模式。

主要方法：

* 使用全年负荷、光伏和实时电价数据；
* 基于历史数据构建日前预测；
* 使用线性规划求解日前购电计划；
* 通过日内 MPC 对剩余时段进行滚动优化；
* 使用 PCHIP（分段三次 Hermite 插值）处理整点光伏预测数据；
* 使用实时 EMS 状态机模拟储能响应及紧急购电。

**论文给出的主要结果：**

在波动电价场景下，MPC
能够利用日内低价窗口调整购电计划，降低高价时段紧急购电带来的成本风险。

论文报告：2025 年 12 月 21 日电费降低 8.4%，2025 年 9 月 23 日电费降低
16.3%。

## 8\. 运行方法

建议使用 Python 3.10 或以上版本创建独立虚拟环境，并在安装依赖后运行。

``` bash
# 创建虚拟环境
python -m venv .venv

# Windows 激活环境
.venv\\Scripts\\activate

# 安装依赖
pip install -r requirements.txt
```

从项目根目录运行对应程序：

``` bash
python src/question1.py
python src/question2.py
python src/question3.py
python src/question4.py
```

四个程序分别对应四个建模问题，可根据需要独立运行。

**数据路径说明：** 当前代码使用 `附件1.xlsx`
等相对路径读取数据。运行时需要确保数据文件位于程序预期的当前工作目录中。若将数据放在
`data/` 文件夹，需要相应修改代码中的文件路径，或统一配置数据目录。

## 10\. 项目特点与工作亮点

1. **模型逐层递进：**
从确定性线性规划扩展到不确定性鲁棒调度，再到多阶段 MPC
和实时波动电价优化。
2. **物理约束与经济目标结合：**
综合考虑供需平衡、储能容量、充放电功率和效率约束，以购电成本为核心优化目标。
3. **滚动时序仿真：** 基于 10
分钟调度粒度开展全年逐日仿真，体现储能状态的跨日连续变化。
4. **多策略对比：**
对比日前鲁棒计划与日内动态调整策略，分析预测更新对紧急购电和经济成本的影响。
5. **结果可视化：** 使用 Matplotlib 输出时序曲线、SOC
轨迹、费用结构和灵敏度分析图表。
